# Privacy data flow
Account/profile, notes, documents, source text, embeddings, learning history, conversations, job metadata, and AI usage are stored in PostgreSQL/object storage; Redis holds transient queue/cache state. Selected prompts/context may be transmitted to configured AI/search/OCR providers. Passwords are hashed; reset/refresh tokens are stored only as hashes. Logs must exclude content and secrets. `/privacy/export` returns portable user-owned JSON; `/privacy/delete-account` removes object storage then cascade-owned database records. Production policy must define retention windows, subprocessors, legal basis, and backup tombstone expiry.
