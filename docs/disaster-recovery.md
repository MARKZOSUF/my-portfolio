# Disaster recovery
Targets (to approve): RPO 24h, RTO 4h. Take encrypted daily PostgreSQL base backups plus WAL archiving, enable S3 versioning/lifecycle/replication, and treat Redis as rebuildable except active Celery jobs. Quarterly drill: provision isolated network, restore object snapshot and database, apply migrations, validate row/object counts and ownership, rotate secrets, reconnect workers, and record actual RPO/RTO. Before migrations: backup, test upgrade/downgrade/upgrade in staging, canary API/worker, and preserve rollback image. Never test restore over production.
